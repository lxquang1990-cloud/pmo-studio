# Asset Management Source Brief

Khách hàng cần hệ thống Quản lý trang thiết bị, tài sản nội bộ.

## Goals
- Số hóa danh mục tài sản/TTB: mã tài sản, tên, nhóm, serial, phòng ban, người sử dụng, ngày mua, nguyên giá, tình trạng.
- Quản lý cấp phát, bàn giao, thu hồi, điều chuyển tài sản theo nhân viên/phòng ban.
- Ghi nhận kiểm kê, bảo trì/sửa chữa, bảo hành, thanh lý và lịch sử biến động.
- Có báo cáo/dashboard theo phòng ban, người dùng, nhóm tài sản, trạng thái, kỳ kiểm kê.
- Có phân quyền Admin, Asset Manager, Department Manager, Staff, Auditor.

## MVP Scope
- Asset master and classification.
- Allocation, handover, return, transfer.
- Inventory, maintenance, liquidation request.
- Report/export.
- Permission, audit log, import/export validation.

## Phase 2 / Optional
- RFID full integration after device/vendor PoC.
- Realtime HRM/ERP/accounting API after API contract.
- Legal digital signature after provider/license confirmation.
- Advanced configurable workflow/rule engine if approval rules become complex.

## Acceptance Hints
- asset_code is generated by the system; user enters serial/external reference.
- Invalid import rows should be rejected with row-level errors while valid rows continue.
- Unauthorized UI/API action must return access denied/403 and write a security audit event.
- Report export must include asset_code, name, group, holder, department, status, original_cost and date columns.
